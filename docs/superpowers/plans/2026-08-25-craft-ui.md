# craft UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `superb:craft` a local browser front-end, so the agent posts rounds of questions as JSON, watches for replies, folds them into `CRAFT.md`, and posts the next round until the vision is clear or the user presses Finish.

**Architecture:** A zero-dependency Python 3 web server ships inside the skill. The agent writes `round-NNN.questions.json` into `<project>/.craft/`; the server serves the highest-numbered round to a single self-contained HTML page; the page autosaves a draft on every change and POSTs the full answer set on Send; the agent blocks on a `wait` command that exits when answers land. `CRAFT.md` stays the artifact of record — written only by the agent, rendered read-only into the page's sidebar.

**Tech Stack:** Python 3.9+ stdlib only (`http.server`, `json`, `unittest`). One self-contained HTML file — no framework, no build step, no package manager.

**Spec:** `docs/superpowers/specs/2026-08-25-craft-ui-design.md`

## Global Constraints

- **Python 3.9 or newer, standard library only.** No third-party import may appear anywhere under `plugins/superb/skills/craft/ui/`. No `pip`, no `requirements.txt`, no build step, no package manager.
- **`app.html` must be entirely self-contained.** No `<script src=`, no remote `<link>`, no CDN, no webfont. The page must work with the machine offline.
- **The server binds `127.0.0.1` only**, and every request requires the session key (query string `?key=` or the `craftkey` cookie). Anything else gets `403`.
- **The server never writes `CRAFT.md`.** It reads it. The agent is the only writer.
- **`importance` is exactly one of** `REQUIRED`, `IMPORTANT`, `PREFERENCE`, `OPTIONAL`.
- **`type` is exactly one of** `single`, `multi`, `text`, `longtext`.
- **Exit codes:** `0` submitted or finished · `2` `TIMEOUT` · `3` `NOSERVER` · `4` `LOCKED`.
- **Every task ends with `tools/test-craftui.sh` green**, not just the task's own test.
- **Commits are authored `kardebadas <16806320+kardebadas@users.noreply.github.com>`.** Never add `Co-Authored-By`, "Generated with…", any other attribution trailer, or any session link, in a commit message or in any file.

"""Session directory, atomic writes and round discovery for the craft UI.

The session directory lives beside CRAFT.md in the user's project. Nothing in
this module knows anything about HTTP, and nothing here ever writes CRAFT.md.
"""
from __future__ import annotations

import json
import os
import re
import tempfile
from pathlib import Path

ROUND_RE = re.compile(r"^round-(\d{3})\.questions\.json$")


def write_json_atomic(path, obj):
    """Write obj as JSON so a reader never sees a half-written file."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=str(path.parent), prefix=".tmp-", suffix=".json")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as fh:
            json.dump(obj, fh, indent=2, ensure_ascii=False)
            fh.flush()
            os.fsync(fh.fileno())
        os.replace(tmp, path)
    except BaseException:
        try:
            os.unlink(tmp)
        except OSError:
            pass
        raise


def read_json(path):
    """Read JSON. Raises ValueError (JSONDecodeError) if the file is malformed."""
    return json.loads(Path(path).read_text(encoding="utf-8"))


class Session:
    def __init__(self, project_dir):
        self.project_dir = Path(project_dir).resolve()
        self.craft_dir = self.project_dir / ".craft"
        self.brief_path = self.project_dir / "CRAFT.md"

    def ensure_dirs(self):
        self.craft_dir.mkdir(parents=True, exist_ok=True)

    def questions_path(self, n):
        return self.craft_dir / "round-{:03d}.questions.json".format(n)

    def draft_path(self, n):
        return self.craft_dir / "round-{:03d}.draft.json".format(n)

    def answers_path(self, n):
        return self.craft_dir / "round-{:03d}.answers.json".format(n)

    def current_round(self):
        """The highest-numbered round the agent has written, or None."""
        if not self.craft_dir.is_dir():
            return None
        found = []
        for entry in self.craft_dir.iterdir():
            match = ROUND_RE.match(entry.name)
            if match:
                found.append(int(match.group(1)))
        return max(found) if found else None

    def read_brief(self):
        try:
            return self.brief_path.read_text(encoding="utf-8")
        except FileNotFoundError:
            return ""
```

class SessionLockTest(unittest.TestCase):
    def setUp(self):
        self._tmp = tempfile.TemporaryDirectory()
        self.s = Session(self._tmp.name)
        self.s.ensure_dirs()

    def tearDown(self):
        self._tmp.cleanup()

    @staticmethod
    def _dead_pid():
        proc = subprocess.Popen([sys.executable, "-c", "pass"])
        proc.wait()
        return proc.pid

    def test_acquiring_writes_our_pid(self):
        self.s.acquire_lock()
        self.assertEqual(read_json(self.s.lock_path)["pid"], os.getpid())

    def test_a_live_lock_is_refused(self):
        self.s.acquire_lock()
        with self.assertRaises(LockHeld) as caught:
            Session(self.s.project_dir).acquire_lock()
        self.assertEqual(caught.exception.pid, os.getpid())
        self.assertTrue(caught.exception.started_at)

    def test_a_stale_lock_is_reclaimed(self):
        write_json_atomic(self.s.lock_path, {"pid": self._dead_pid(), "started_at": "old"})
        self.s.acquire_lock()
        self.assertEqual(read_json(self.s.lock_path)["pid"], os.getpid())

    def test_a_corrupt_lock_is_reclaimed(self):
        self.s.lock_path.write_text("{not json", encoding="utf-8")
        self.s.acquire_lock()
        self.assertEqual(read_json(self.s.lock_path)["pid"], os.getpid())

    def test_force_takes_over_a_live_lock(self):
        write_json_atomic(self.s.lock_path, {"pid": os.getpid(), "started_at": "now"})
        other = Session(self.s.project_dir)
        other.acquire_lock(force=True)
        self.assertEqual(read_json(self.s.lock_path)["pid"], os.getpid())

    def test_release_removes_the_lock(self):
        self.s.acquire_lock()
        self.s.release_lock()
        self.assertFalse(self.s.lock_path.exists())
        Session(self.s.project_dir).acquire_lock()  # must not raise

    def test_release_leaves_someone_elses_lock_alone(self):
        write_json_atomic(self.s.lock_path, {"pid": 1, "started_at": "old"})
        self.s.release_lock()
        self.assertTrue(self.s.lock_path.exists())

    def test_pid_alive_agrees_with_reality(self):
        self.assertTrue(pid_alive(os.getpid()))
        self.assertFalse(pid_alive(self._dead_pid()))

class LockHeld(Exception):
    """Raised when another live craft session owns this project directory."""

    def __init__(self, pid, started_at):
        self.pid = pid
        self.started_at = started_at
        super().__init__(
            "craft session pid {} (started {}) owns this project".format(pid, started_at)
        )


def pid_alive(pid):
    try:
        os.kill(int(pid), 0)
    except (ProcessLookupError, ValueError, TypeError):
        return False
    except PermissionError:
        return True  # exists, owned by someone else
    return True
```

Add these methods to `Session`:

```python
    @property
    def lock_path(self):
        return self.craft_dir / "session.lock"

    def _read_lock(self):
        try:
            return read_json(self.lock_path)
        except (FileNotFoundError, ValueError):
            return None

    def acquire_lock(self, force=False):
        """Take the session lock. CRAFT.md is rewritten whole every round, so two
        sessions on one project silently lose one session's answers."""
        self.ensure_dirs()
        for _ in range(5):
            try:
                fd = os.open(str(self.lock_path), os.O_CREAT | os.O_EXCL | os.O_WRONLY, 0o644)
            except FileExistsError:
                holder = self._read_lock()
                if holder and pid_alive(holder.get("pid")) and not force:
                    raise LockHeld(holder.get("pid"), holder.get("started_at", "unknown"))
                try:
                    os.unlink(str(self.lock_path))
                except FileNotFoundError:
                    pass
                continue
            with os.fdopen(fd, "w", encoding="utf-8") as fh:
                json.dump(
                    {
                        "pid": os.getpid(),
                        "started_at": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
                    },
                    fh,
                )
            return
        raise LockHeld("unknown", "unknown")

    def release_lock(self):
        """Remove the lock, but only if it is ours."""
        holder = self._read_lock()
        if holder is None or holder.get("pid") == os.getpid():
            try:
                os.unlink(str(self.lock_path))
            except FileNotFoundError:
                pass
```

"""Validation for the craft UI wire format.

Four answer states are kept deliberately distinct: answered, delegated
("I don't care, record it and stop asking"), skipped ("ask me again"), and
absent, which means the same as skipped.
"""
from __future__ import annotations

IMPORTANCES = ("REQUIRED", "IMPORTANT", "PREFERENCE", "OPTIONAL")
TYPES = ("single", "multi", "text", "longtext")
CHOICE_TYPES = ("single", "multi")


def validate_round(obj):
    """Return a list of human-readable problems. Empty list means valid."""
    if not isinstance(obj, dict):
        return ["round must be a JSON object"]

    errors = []
    if not isinstance(obj.get("round"), int):
        errors.append("round: missing or not an integer")

    questions = obj.get("questions")
    if not isinstance(questions, list):
        errors.append("questions: missing or not a list")
        return errors

    seen = set()
    for index, question in enumerate(questions):
        where = "questions[{}]".format(index)
        if not isinstance(question, dict):
            errors.append("{}: not an object".format(where))
            continue

        qid = question.get("id")
        if not isinstance(qid, str) or not qid:
            errors.append("{}: id missing".format(where))
        elif qid in seen:
            errors.append("{}: duplicate id {}".format(where, qid))
        else:
            seen.add(qid)

        if question.get("importance") not in IMPORTANCES:
            errors.append(
                "{}: importance must be one of {}".format(where, "/".join(IMPORTANCES))
            )

        title = question.get("title")
        if not isinstance(title, str) or not title:
            errors.append("{}: title missing".format(where))

        qtype = question.get("type")
        if qtype not in TYPES:
            errors.append("{}: type must be one of {}".format(where, "/".join(TYPES)))
        elif qtype in CHOICE_TYPES:
            options = question.get("options")
            if not isinstance(options, list) or not options:
                errors.append(
                    "{}: type {} requires a non-empty options list".format(where, qtype)
                )
            else:
                for j, option in enumerate(options):
                    if not isinstance(option, dict) or not isinstance(option.get("value"), str):
                        errors.append("{}.options[{}]: needs a string value".format(where, j))

    return errors


def answer_state(ans):
    """One of "answered", "delegated", "skipped"."""
    if not isinstance(ans, dict):
        return "skipped"
    if ans.get("delegated") is True:
        return "delegated"
    if ans.get("skipped") is True:
        return "skipped"
    choice = ans.get("choice")
    if isinstance(choice, list) and choice:
        return "answered"
    if isinstance(choice, str) and choice.strip():
        return "answered"
    for key in ("text", "other"):
        value = ans.get(key)
        if isinstance(value, str) and value.strip():
            return "answered"
    return "skipped"


def count_open(round_obj, answers):
    """How many questions of each importance are still waiting for the user."""
    answers = answers or {}
    counts = dict((level, 0) for level in IMPORTANCES)
    for question in (round_obj or {}).get("questions", []):
        importance = question.get("importance")
        if importance not in counts:
            continue
        if answer_state(answers.get(question.get("id"))) == "skipped":
            counts[importance] += 1
    return counts


def count_answered(round_obj, answers):
    """Answered or deliberately delegated — both are settled."""
    answers = answers or {}
    settled = 0
    for question in (round_obj or {}).get("questions", []):
        if answer_state(answers.get(question.get("id"))) in ("answered", "delegated"):
            settled += 1
    return settled

### Task 4: The markdown renderer

> **⚠️ THE LINK RULE BELOW IS A LIVE XSS HOLE. Do not copy it anywhere.**
> `html.escape(quote=False)` leaves `"` intact, and the link target is the only
> brief text that lands inside an HTML attribute. `[x](https://a"onmouseover=…)`
> therefore renders as a real event handler — confirmed with the stdlib HTML
> tokenizer, which parses `onmouseover` as a genuine attribute. `javascript:`
> and `data:` targets rendered live too, control characters walked a scheme past
> naive checks, and the regex was quadratic (40k unmatched brackets cost 4.4 s on
> a single-threaded server that renders on every poll).
>
> What shipped instead: a `_href()` that strips control characters, allowlists
> `http`/`https`/`mailto` (scheme-less relatives still fine), entity-escapes `"`
> and `'`, and renders a refused target as inert literal markdown — plus a

```python
"""CRAFT.md -> HTML, in about a hundred lines of stdlib.

Escaping happens first, before any transformation, so a brief containing
angle brackets is safe. Covers headings, bold, italic, inline and fenced
code, links, bullet and numbered lists, blockquotes and rules. Not tables.
"""
from __future__ import annotations

import html as _html
import re

_FENCE = re.compile(r"^```")
_HEADING = re.compile(r"^(#{1,6})\s+(.*)$")
_RULE = re.compile(r"^(-{3,}|\*{3,}|_{3,})$")
_BULLET = re.compile(r"^[-*+]\s+(.*)$")
_NUMBER = re.compile(r"^\d+[.)]\s+(.*)$")
_CODE = re.compile(r"`([^`\n]+?)`")
_BOLD = re.compile(r"\*\*(.+?)\*\*")
_ITALIC = re.compile(r"(?<![*\w])\*([^*\n]+?)\*(?!\*)")
_LINK = re.compile(r"\[([^\]]+)\]\(([^)\s]+)\)")


def _inline(text):
    text = _CODE.sub(lambda m: "<code>{}</code>".format(m.group(1)), text)
    text = _BOLD.sub(lambda m: "<strong>{}</strong>".format(m.group(1)), text)
    text = _ITALIC.sub(lambda m: "<em>{}</em>".format(m.group(1)), text)
    text = _LINK.sub(
        lambda m: '<a href="{}" target="_blank" rel="noreferrer">{}</a>'.format(
            m.group(2), m.group(1)
        ),
        text,
    )
    return text


def render(text):
    lines = _html.escape(text or "", quote=False).split("\n")
    out = []
    list_tag = [None]

    def close_list():
        if list_tag[0]:
            out.append("</{}>".format(list_tag[0]))
            list_tag[0] = None

    def open_list(tag):
        if list_tag[0] != tag:
            close_list()
            out.append("<{}>".format(tag))
            list_tag[0] = tag

    i = 0
    while i < len(lines):
        stripped = lines[i].strip()

        if _FENCE.match(stripped):
            close_list()
            i += 1
            buffer = []
            while i < len(lines) and not _FENCE.match(lines[i].strip()):
                buffer.append(lines[i])
                i += 1
            i += 1  # step past the closing fence, or past the end
            out.append("<pre><code>{}</code></pre>".format("\n".join(buffer)))
            continue

        if not stripped:
            close_list()
            i += 1
            continue

        heading = _HEADING.match(stripped)
        if heading:
            close_list()
            level = len(heading.group(1))
            out.append("<h{0}>{1}</h{0}>".format(level, _inline(heading.group(2))))
            i += 1
            continue

        if _RULE.match(stripped):
            close_list()
            out.append("<hr>")
            i += 1
            continue

        if stripped.startswith("&gt;"):
            close_list()
            out.append("<blockquote>{}</blockquote>".format(_inline(stripped[4:].strip())))
            i += 1
            continue

        bullet = _BULLET.match(stripped)
        if bullet:
            open_list("ul")
            out.append("<li>{}</li>".format(_inline(bullet.group(1))))
            i += 1
            continue

        number = _NUMBER.match(stripped)
        if number:
            open_list("ol")
            out.append("<li>{}</li>".format(_inline(number.group(1))))
            i += 1
            continue

        close_list()
        out.append("<p>{}</p>".format(_inline(stripped)))
        i += 1

    close_list()
    return "\n".join(out)
```

"""HTTP surface for the craft UI.

Deliberately stupid: it moves JSON between the agent's files and the browser
and renders CRAFT.md for display. It makes no product decisions, contacts no
model, and never writes CRAFT.md.
"""
from __future__ import annotations

import json
import secrets
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import parse_qs, urlparse

import markdown
import schema
from session import read_json

APP_HTML = Path(__file__).with_name("app.html")
COOKIE = "craftkey"


def make_key():
    return secrets.token_hex(32)


class _Handler(BaseHTTPRequestHandler):
    server_version = "craftui"

    def log_message(self, fmt, *args):
        pass  # the agent's terminal is not a web log

    def _authed(self):
        key = self.server.key
        supplied = parse_qs(urlparse(self.path).query).get("key", [None])[0]
        if supplied == key:
            return True
        return "{}={}".format(COOKIE, key) in (self.headers.get("Cookie") or "")

    def _send(self, code, body, ctype="application/json", set_cookie=False):
        data = body.encode("utf-8") if isinstance(body, str) else body
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(data)))
        self.send_header("Cache-Control", "no-store")
        if set_cookie:
            self.send_header(
                "Set-Cookie", "{}={}; Path=/; SameSite=Strict".format(COOKIE, self.server.key)
            )
        self.end_headers()
        self.wfile.write(data)

    def _json(self, obj, code=200):
        self._send(code, json.dumps(obj), "application/json")

    def do_GET(self):
        self.server.touch()
        if not self._authed():
            return self._send(403, "forbidden", "text/plain")
        path = urlparse(self.path).path
        if path == "/":
            return self._send(
                200, APP_HTML.read_bytes(), "text/html; charset=utf-8", set_cookie=True
            )
        if path == "/api/round":
            return self._json(self.server.round_payload())
        if path == "/api/brief":
            return self._json({"html": markdown.render(self.server.session.read_brief())})
        return self._send(404, "not found", "text/plain")


class CraftServer(ThreadingHTTPServer):
    daemon_threads = True
    allow_reuse_address = True

    def __init__(self, session, key, host="127.0.0.1", port=0, idle_timeout_s=14400):
        ThreadingHTTPServer.__init__(self, (host, port), _Handler)
        self.session = session
        self.key = key
        self.idle_timeout_s = idle_timeout_s
        self._last = time.monotonic()

    @property
    def port(self):
        return self.server_address[1]

    def touch(self):
        self._last = time.monotonic()

    def idle_seconds(self):
        return time.monotonic() - self._last

    def round_payload(self):
        number = self.session.current_round()
        if number is None:
            return {"ok": True, "round": None}
        name = self.session.questions_path(number).name
        try:
            obj = read_json(self.session.questions_path(number))
        except ValueError as exc:
            return {"ok": False, "error": "{} is not valid JSON: {}".format(name, exc)}
        except OSError as exc:
            return {"ok": False, "error": "{} could not be read: {}".format(name, exc)}
        errors = schema.validate_round(obj)
        if errors:
            return {"ok": False, "error": "{} is invalid".format(name), "details": errors}
        return {"ok": True, "round": obj}

#!/usr/bin/env python3
"""craft UI command line: serve, wait, status, stop.

Exit codes: 0 ok · 2 TIMEOUT · 3 NOSERVER · 4 LOCKED.
"""
from __future__ import annotations

import argparse
import json
import os
import signal
import socket
import subprocess
import sys
import threading
import time
import webbrowser
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from server import CraftServer, make_key  # noqa: E402
from session import LockHeld, Session, read_json, write_json_atomic  # noqa: E402

SERVE_START_TIMEOUT_S = 15


def info_path(session):
    return session.craft_dir / "server-info"


def error_path(session):
    return session.craft_dir / "serve-error"


def read_server_info(session):
    try:
        return read_json(info_path(session))
    except (FileNotFoundError, ValueError):
        return None


def _pid_alive(pid):
    """Is this pid running? Used ONLY to ask whether our own server process is
    still up — never for mutual exclusion. Deciding who owns the project from a
    pid is the bug the kernel lock exists to remove; see Task 2's note."""
    try:
        os.kill(int(pid), 0)
    except (ProcessLookupError, ValueError, TypeError):
        return False
    except PermissionError:
        return True
    return True


def server_alive(session):
    info = read_server_info(session)
    return bool(info and _pid_alive(info.get("pid")))


def _port_free(port):
    if not port:
        return False
    with socket.socket() as probe:
        try:
            probe.bind(("127.0.0.1", int(port)))
            return True
        except OSError:
            return False


def _pick_port(session, requested):
    """Reuse the last port when it is free, so an open tab reconnects itself."""
    if requested:
        return int(requested)
    info = read_server_info(session)
    if info and _port_free(info.get("port")):
        return int(info["port"])
    return 0


# --------------------------------------------------------------------- serve


def _serve_child(args):
    """The actual server process. Owns the lock for its whole life."""
    session = Session(args.project_dir)
    session.ensure_dirs()
    try:
        session.acquire_lock()
    except LockHeld as exc:
        write_json_atomic(
            error_path(session),
            {"exit_code": 4, "pid": exc.pid, "started_at": exc.started_at},
        )
        return 4

    try:
        error_path(session).unlink()
    except FileNotFoundError:
        pass

    key = make_key()
    server = CraftServer(
        session, key, port=_pick_port(session, args.port),
        idle_timeout_s=args.idle_timeout_minutes * 60.0,
    )
    payload = {
        "type": "server-started",
        "port": server.port,
        "pid": os.getpid(),
        "key": key,
        "url": "http://localhost:{}/?key={}".format(server.port, key),
    }

    def cleanup(*_):
        try:
            info_path(session).unlink()
        except FileNotFoundError:
            pass
        session.release_lock()

    def on_signal(*_):
        threading.Thread(target=server.shutdown, daemon=True).start()

    signal.signal(signal.SIGTERM, on_signal)
    signal.signal(signal.SIGINT, on_signal)

    def watchdog():
        while True:
            time.sleep(1.0)
            # If our lock file was removed or replaced under us, another session
            # can already have acquired the project and be rewriting CRAFT.md.
            # No acquirer-side check can prevent that -- once the name is gone
            # there is nothing left to compare against -- so the holder is the
            # only party that can still notice. Say so loudly and get out.
            if not session.verify_lock_still_ours():
                sys.stderr.write(
                    "craftui: {} was removed or replaced; another session may "
                    "now hold this project. Shutting down rather than risk two "
                    "writers on CRAFT.md.\n".format(session.lock_path))
                server.shutdown()
                return
            if server.idle_seconds() > server.idle_timeout_s:
                server.shutdown()
                return

    threading.Thread(target=watchdog, daemon=True).start()
    write_json_atomic(info_path(session), payload)
    try:
        server.serve_forever()
    finally:
        server.server_close()
        cleanup()
    return 0


def cmd_serve(args):
    session = Session(args.project_dir)
    session.ensure_dirs()
    for path in (info_path(session), error_path(session)):
        try:
            path.unlink()
        except FileNotFoundError:
            pass

    child = [sys.executable, os.path.abspath(__file__), "serve",
             "--project-dir", str(session.project_dir),
             "--idle-timeout-minutes", str(args.idle_timeout_minutes),
             "--_child"]
    if args.port:
        child += ["--port", str(args.port)]
    subprocess.Popen(child, start_new_session=True,
                     stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

    deadline = time.time() + SERVE_START_TIMEOUT_S
    while time.time() < deadline:
        failure = None
        try:
            failure = read_json(error_path(session))
        except (FileNotFoundError, ValueError):
            pass
        if failure:
            print("LOCKED  another craft session (pid {}, started {}) owns {}".format(
                failure.get("pid"), failure.get("started_at"), session.craft_dir))
            print("        that process is still running; stop it, or kill {}".format(
                failure.get("pid")))
            return 4
        info = read_server_info(session)
        if info:
            print(json.dumps(info))
            if args.open:
                webbrowser.open(info["url"])
            return 0
        time.sleep(0.1)

    print("ERROR   the server did not start within {}s".format(SERVE_START_TIMEOUT_S))
    return 1


# ----------------------------------------------------------------------- cli


def build_parser():
    parser = argparse.ArgumentParser(prog="craftui")
    subs = parser.add_subparsers(dest="command", required=True)

    serve = subs.add_parser("serve", help="start the craft UI server")
    serve.add_argument("--project-dir", default=".")
    serve.add_argument("--port", type=int, default=0)
    serve.add_argument("--open", action="store_true")
    serve.add_argument("--idle-timeout-minutes", type=float, default=240.0)
    serve.add_argument("--_child", dest="_child", action="store_true",
                       help=argparse.SUPPRESS)
    serve.set_defaults(func=lambda a: _serve_child(a) if a._child else cmd_serve(a))

    return parser


def main(argv=None):
    args = build_parser().parse_args(argv)
    return args.func(args)


if __name__ == "__main__":
    sys.exit(main())

# ---------------------------------------------------------------------- wait

POLL_S = 0.25
DEAD_SERVER_STRIKES = 8  # ~2 s of consecutive misses, so a restart does not trip it


def cmd_wait(args):
    session = Session(args.project_dir)
    answers = session.answers_path(args.round)
    deadline = time.monotonic() + args.timeout
    strikes = 0

    while True:
        if answers.exists():
            try:
                payload = read_json(answers)
            except ValueError:
                time.sleep(POLL_S)  # mid-write; try again
                continue
            token = "FINISHED" if payload.get("finished") else "SUBMITTED"
            print("{} round={} answers={}".format(token, args.round, answers))
            return 0

        strikes = 0 if server_alive(session) else strikes + 1
        if strikes >= DEAD_SERVER_STRIKES:
            print("NOSERVER")
            return 3

        if time.monotonic() >= deadline:
            print("TIMEOUT round={}".format(args.round))
            return 2
        time.sleep(POLL_S)

def cmd_status(args):
    session = Session(args.project_dir)
    info = read_server_info(session)
    # Deliberately NOT reported: who holds the lock. The lock file is never
    # unlinked, so its contents outlive the session that wrote them — reading a
    # pid out of it reports a dead process, and later a recycled one. Whether a
    # server is up is `server`, below, which is what callers actually need.
    report = {
        "server": server_alive(session),
        "port": (info or {}).get("port"),
        "url": (info or {}).get("url"),
        "round": None,
        "has_draft": False,
        "total_questions": 0,
        "answered": 0,
        "open": dict((level, 0) for level in schema.IMPORTANCES),
    }

    number = session.current_round()
    if number is None:
        print(json.dumps(report))
        return 0

    report["round"] = number
    name = session.questions_path(number).name
    try:
        round_obj = read_json(session.questions_path(number))
    except (ValueError, OSError) as exc:
        report["error"] = "{} could not be read: {}".format(name, exc)
        print(json.dumps(report))
        return 0

    errors = schema.validate_round(round_obj)
    if errors:
        report["error"] = "{} is invalid".format(name)
        report["details"] = errors
        print(json.dumps(report))
        return 0

    answers = {}
    for path, flag in ((session.answers_path(number), False),
                       (session.draft_path(number), True)):
        try:
            answers = read_json(path).get("answers") or {}
            report["has_draft"] = flag
            break
        except (FileNotFoundError, ValueError):
            continue

    report["total_questions"] = len(round_obj.get("questions", []))
    report["answered"] = schema.count_answered(round_obj, answers)
    report["open"] = schema.count_open(round_obj, answers)
    print(json.dumps(report))
    return 0


def cmd_stop(args):
    session = Session(args.project_dir)
    info = read_server_info(session)
    if not info or not _pid_alive(info.get("pid")):
        print("NOSERVER")
        return 3
    try:
        os.kill(int(info["pid"]), signal.SIGTERM)
    except ProcessLookupError:
        print("NOSERVER")
        return 3
    deadline = time.time() + 10
    while time.time() < deadline and _pid_alive(info.get("pid")):
        time.sleep(0.1)
    print("STOPPED")
    return 0

// MUST mirror schema.answer_state exactly. A review of Task 3 found three
// divergences in an earlier draft of this function, each of which would have
// silently changed what the user's answers mean:
//   * `if (a.delegated)` is truthiness; Python requires `is True`. Task 3 has a
//     test deliberately pinning that a malformed flag must NOT manufacture a
//     Delegated Decision -- and a Delegated Decision is never asked again.
//   * a choice entry that is empty or whitespace is NOT an answer.
//   * an unrecognised importance must be dropped, not given its own counter key.
// If you change either side, change both, and re-run schema.py's tests.
function answerState(a) {
  if (!a) return "skipped";
  if (a.delegated === true) return "delegated";
  if (a.skipped === true) return "skipped";
  //   * a null/undefined entry is NOT an answer. String(null) is "null", which
  //     is truthy -- Python's `entry is not None` says skipped, so mirror that.
  const chose = (a.choice || []).some(v =>
    v === null || v === undefined ? false
      : typeof v === "string" ? v.trim() !== "" : true);
  if (chose || (a.text || "").trim() || (a.other || "").trim()) return "answered";
  return "skipped";
}

}

```javascript
// ------------------------------------------------------------ autosave

let saveTimer = null;
let lastSeenRound = null;

function scheduleSave() {
  updateCounts();
  clearTimeout(saveTimer);
  saveTimer = setTimeout(saveDraft, 400);
}

async function saveDraft() {
  if (!currentRound) return;
  try {
    await fetch(api("/api/draft"), {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ round: currentRound.round, answers: collectAnswers() }),
    });
    setStatus("saved");
  } catch (err) {
    setStatus("offline");
  }
}

document.getElementById("questions").addEventListener("input", scheduleSave);
document.getElementById("questions").addEventListener("change", scheduleSave);
document.getElementById("questions").addEventListener("click", event => {
  if (event.target.closest(".delegate")) scheduleSave();
});

function setStatus(text) { document.getElementById("status").textContent = text; }

// ------------------------------------------------------- restore a draft

async function restoreDraft() {
  if (!currentRound) return;
  const stored = await (await fetch(api("/api/draft?round=" + currentRound.round))).json();
  const answers = stored.answers || {};
  document.querySelectorAll("#questions .question").forEach(card => {
    const answer = answers[card.dataset.id];
    if (!answer) return;
    if (answer.delegated) {
      const button = card.querySelector(".delegate");
      if (button) button.setAttribute("aria-pressed", "true");
    }
    (answer.choice || []).forEach(value => {
      const input = card.querySelector('input[value="' + CSS.escape(value) + '"]');
      if (input) input.checked = true;
    });
    for (const [selector, value] of [["[data-other]", answer.other],
                                     ["[data-text]", answer.text],
                                     ["[data-note]", answer.note]]) {
      const field = card.querySelector(selector);
      if (field && value) field.value = value;
    }
  });
  updateCounts();
}

// ----------------------------------------------------------- send/finish

async function submit(finished) {
  if (!currentRound) return;
  clearTimeout(saveTimer);
  await fetch(api("/api/submit"), {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ round: currentRound.round, answers: collectAnswers(),
                           finished: finished }),
  });
  if (finished) {
    document.getElementById("waiting").querySelector("h2").textContent =
      "Sent. Claude is writing the final brief.";
  }
  lastSeenRound = currentRound.round;
  document.getElementById("waiting").setAttribute("data-on", "1");
  pollForNextRound();
}

document.getElementById("send").addEventListener("click", () => submit(false));
document.getElementById("finish").addEventListener("click", () => {
  const open = document.getElementById("counts").textContent;
  const message = "Finish the crafting session?\n\n" + open +
    "\n\nClaude will write the final brief from what you have answered.";
  if (confirm(message)) submit(true);
});

// ------------------------------------------------------ between rounds

async function pollForNextRound() {
  while (true) {
    await new Promise(resolve => setTimeout(resolve, 1000));
    try {
      const payload = await (await fetch(api("/api/round"))).json();
      document.getElementById("overlay").removeAttribute("data-on");
      if (payload.ok && payload.round && payload.round.round !== lastSeenRound) {
        document.getElementById("waiting").removeAttribute("data-on");
        renderRound(payload.round);
        await restoreDraft();
        await loadBrief();
        return;
      }
    } catch (err) {
      document.getElementById("overlay").setAttribute("data-on", "1");
    }
  }
}

// ------------------------------------------------------------- heartbeat

setInterval(async () => {
  try {
    await fetch(api("/api/round"));
    document.getElementById("overlay").removeAttribute("data-on");
  } catch (err) {
    document.getElementById("overlay").setAttribute("data-on", "1");
  }
}, 5000);

(async function start() {
  await loadRound();
  await restoreDraft();
  await loadBrief();
})();
```

# 2b. Delivery — the browser, or the file

Decide **once, at the start of the session**, how questions reach me. Then
say which mode you are in, in one line, and stay in it.

* `/superb:craft ui` — browser. `/superb:craft file` — `CRAFT.md`.
* With no argument: try the browser, fall back to the file.

## Starting the browser mode

```sh
python3 <skill>/ui/craftui.py serve --project-dir . --open
```

It prints one line of JSON with a `url`. Give me that **complete** URL,
query string included — the server refuses requests without the key.

If `python3` is missing, or the command fails, or it prints `LOCKED`, say so
in **one line** and continue in file mode. A crafting session is never
blocked by a web server.

`LOCKED` means another craft session is **live** on this project right now —
the lock is held by the kernel, so it cannot be stale. There is no override
flag and you must not invent one. Tell me the pid it names and let me decide
whether to stop that session; then carry on in file mode meanwhile.

Add `.craft/` to the project's `.gitignore` if nothing covers it, and say so
in one line.

## The consequence that changes what you write

**In browser mode, `CRAFT.md` holds only the accumulated brief. Never the
questionnaire.** Questions live in `.craft/round-NNN.questions.json`.

In file mode `CRAFT.md` holds both, exactly as §2 describes.

Writing the questionnaire into `CRAFT.md` while a browser session is live
means I answer the same questions in two places and you fold in two
conflicting sets. Do not do it, however helpful it seems.

## The loop

1. Write `.craft/round-NNN.questions.json`. Every question is an object with
   `id`, `importance` (one of REQUIRED / IMPORTANT / PREFERENCE / OPTIONAL),
   `title`, `type` (`single` / `multi` / `text` / `longtext`), and optionally
   `area`, `why`, `options` (required for `single` and `multi`), `allow_other`,
   `delegable`. Put the decisions, assumptions, contradictions and delegated
   decisions in the `ledger` object so they show in the sidebar.
2. Run `python3 <skill>/ui/craftui.py wait --project-dir . --round NNN`
   **as a background command**, and end your turn. Do not poll in a loop, and
   do not ask me in chat what I am answering in the browser.
3. `SUBMITTED` or `FINISHED` → read the answers file. `TIMEOUT` → run `wait`
   again; it is a heartbeat, not a failure. `NOSERVER` → the server died;
   restart it and tell me the URL.
4. Fold the answers into `CRAFT.md`, then write the next round. The
   questionnaire gets **smaller** every pass, exactly as §"Second pass" says.

## Reading the answers

Four states, and they are not the same thing:

| In the file | Means |
|---|---|
| `"choice"` / `"text"` / `"other"` | Answered. Fold it in and close the question. |
| `"delegated": true` | **I do not care — record it as a Delegated Decision and never ask again.** |
| `"skipped": true` | Still open. Ask it again next round. |
| id absent entirely | Same as skipped. |

A `"note"` is mine in my own words. Fold it in as a qualifier; never discard
it because the `choice` beside it looked sufficient.

## Ending

`FINISHED` means **I have stopped answering.** It does not mean the vision is
clear. Do the final fold, then judge the brief on its merits: if REQUIRED
questions are still unanswered, name them and report
`CRAFT STATUS: MORE CLARIFICATION NEEDED`. Only a genuinely complete brief
gets `VISION CLEAR`.

If you conclude the vision is clear before I press Finish, write a final round
with an empty `questions` list and a closing note, then stop.
